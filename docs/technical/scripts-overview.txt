HYPR-VOICE SCRIPTS OVERVIEW
============================

Installation & Setup
--------------------
install_deps.sh       - Automated dependency installer
                        • Installs system packages (wl-clipboard, wtype, etc.)
                        • Creates Python virtual environment
                        • Installs Python dependencies
                        • Sets up directories
                        • Adds Hyprland keybinds
                        Usage: ./install_deps.sh

Diagnostics & Testing
---------------------
debug_setup.sh        - Comprehensive system diagnostics
                        • Checks all dependencies
                        • Lists audio devices
                        • Verifies Hyprland integration
                        • Tests clipboard functionality
                        • Validates configuration
                        Usage: ./debug_setup.sh

test_audio.sh         - Audio device testing
                        • Lists available input devices
                        • Tests USB Audio recording
                        • Validates audio levels
                        • Confirms configuration
                        Usage: ./test_audio.sh

Service Management
------------------
run_hypr_voice.sh     - Unified service launcher (PRIMARY SCRIPT)
                        • Starts Whisper server + client
                        • Health checks & monitoring
                        • Log viewing
                        • Status reporting
                        Commands:
                          ./run_hypr_voice.sh start    - Start everything
                          ./run_hypr_voice.sh stop     - Stop everything
                          ./run_hypr_voice.sh restart  - Restart services
                          ./run_hypr_voice.sh status   - Show status
                          ./run_hypr_voice.sh logs     - View logs

hypr-voice-control.sh - Keybind handler (called by Hyprland)
                        • Receives START/STOP/STATUS commands
                        • Communicates via Unix socket
                        • Fast, low-latency control
                        Usage: Called automatically by keybinds

Configuration
-------------
hyprland-keybinds.conf - Hyprland keybind definitions
                         • F9: Push-to-talk (hold to record, release to transcribe)
                         • Super+F9: Status
                         • Super+Shift+F9: Force stop
                         Add to hyprland.conf:
                           source = /path/to/hyprland-keybinds.conf

Legacy Scripts (Don't Use)
---------------------------
setup.sh              - Original setup script (superseded by install_deps.sh)
hyprland_integration.sh - Old integration (superseded by run_hypr_voice.sh)

RECOMMENDED WORKFLOW
====================

1. First Time Setup:
   ./install_deps.sh          # Install everything
   ./test_audio.sh            # Verify audio works
   ./debug_setup.sh           # Check configuration

2. Daily Usage:
   ./run_hypr_voice.sh start  # Start services
   Use Super+Grave in Hyprland to record voice
   ./run_hypr_voice.sh stop   # Stop when done

3. Troubleshooting:
   ./run_hypr_voice.sh status # Check if running
   ./run_hypr_voice.sh logs   # View errors
   ./debug_setup.sh           # Full diagnostics
   ./test_audio.sh            # Test microphone
