## 1. Development Workflow

### Code Review Assistant

**Scenario:** You're reviewing a pull request and want to understand the changes.

**Workflow:**

1. **Activate the Code Agent**
   - Open Web UI: http://localhost:8933
   - Go to Agent Panel
   - Select "Code Worker" agent

2. **Voice Command:**
   ```
   "Review the changes in src/hypr_voice/server.py and highlight any potential issues"
   ```

3. **Agent Response:**
   - Analyzes the file
   - Identifies code quality issues
   - Suggests improvements
   - Explains complex sections

**Alternative (Push-to-Talk):**
```
Press F10 → "What's changed in this file?" → Press F10
```

### Debug Helper

**Scenario:** Your code is throwing an error and you need help fixing it.

**Workflow:**

1. **Read the error:**
   ```bash
   python my_script.py
   # Error: NameError: name 'undefined_var' is not defined
   ```

2. **Voice Query:**
   ```
   "I'm getting a NameError for undefined_var in my_script.py. How do I fix it?"
   ```

3. **Agent Response:**
   - Explains the error
   - Shows the problematic line
   - Provides fix
   - Explains why it happened

**Pro Tip:** Use the Enhanced Context Agent with the file open in your editor:
```
"Fix the error in the current file"
```

### Test Generation

**Scenario:** You need to write unit tests for a function.

**Workflow:**

1. **Voice Command:**
   ```
   "Write unit tests for the calculate_total function in src/calculators.py"
   ```

2. **Agent Response:**
   - Reads the function
   - Generates test cases
   - Includes edge cases
   - Creates test file

**Output Example:**
```python
# Generated by Hypr-Voice
def test_calculate_total_positive():
    assert calculate_total([10, 20, 30]) == 60

def test_calculate_total_empty():
    assert calculate_total([]) == 0

def test_calculate_total_negative():
    with pytest.raises(ValueError):
        calculate_total([-10, -20])
```

### Backup Management

**Scenario:** Set up automated backups.

**Workflow:**

1. **Voice Command:**
   ```
   "Create a backup script for the /home/user/projects directory"
   ```

2. **Agent Response:**
   - Creates backup script
   - Sets up compression
   - Adds timestamping
   - Implements rotation
   - Shows how to schedule with cron

**Generated Script:**
```bash

SOURCE="/home/user/projects"
BACKUP_DIR="/backups"
DATE=$(date +%Y%m%d-%H%M%S)
tar -czf "$BACKUP_DIR/projects-$DATE.tar.gz" "$SOURCE"
```

## Tips for Best Results

### 1. Be Specific

**Good:**
```
"Write a Python function to calculate the fibonacci sequence using memoization"
```

**Less Effective:**
```
"Write a fibonacci function"
```

### 2. Provide Context

**Good:**
```
"In the file src/api/users.py, add validation to the create_user endpoint"
```

**Less Effective:**
```
"Add validation to the user creation"
```

### 3. Use Appropriate Agent

- **Code Agent** → Programming tasks
- **Research Agent** → Information gathering
- **Shell Agent** → System operations
- **Voice Agent** → General conversation
- **Enhanced Context** → Context-sensitive tasks

### 4. Break Down Complex Tasks

Instead of:
```
"Build a complete e-commerce website"
```

Try:
```
"Design the database schema for an e-commerce site"
"Create the API endpoints for product listings"
"Implement the shopping cart functionality"
```

### 5. Iterate and Refine

**First Attempt:**
```
"Create a login page"
```

**Follow-up:**
```
"Add password validation to the login page"
"Add remember me functionality"
"Style the page to match our brand"
```

## Troubleshooting Workflows

### Agent Doesn't Understand

**Problem:** Agent gives irrelevant response.

**Solutions:**
1. **Rephrase Query:**
   ```
   "Let me rephrase: I need help with [specific topic]"
   ```

2. **Provide Context:**
   ```
   "I'm working on [project] and need help with [task]"
   ```

3. **Switch Agent:**
   - Try a different specialized agent

### Voice Recognition Issues

**Problem:** Transcription is inaccurate.

**Solutions:**
1. **Add to Vocabulary:**
   - Add technical terms to custom vocabulary
   - Use Web UI → Vocabulary Dashboard

2. **Improve Audio:**
   - Reduce background noise
   - Speak clearly
   - Get closer to microphone

3. **Use Text Input:**
   ```
   ./scripts/hypr-voice-record.sh --text "Your query"
   ```

### Slow Response Time

**Problem:** Agent takes too long to respond.

**Solutions:**
1. **Check Configuration:**
   - Enable Opus compression
   - Use streaming mode
   - Increase chunk size

2. **Simplify Query:**
   - Break into smaller tasks
   - Be more specific

3. **Check System:**
   - Verify internet connection
   - Check API quota
   - Monitor resource usage
