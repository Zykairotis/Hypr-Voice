## Usage Analysis

### 1. Initialization & Options
Agents are initialized using `ClaudeAgentOptions` with a variety of settings:
- `model`: Primarily `claude-3-5-sonnet-20241022` or `claude-sonnet-4-5`.
- `permission_mode`: Uses `"default"`, `"acceptEdits"`, and `"bypassPermissions"`.
- `setting_sources`: Typically includes `["project"]` to load `CLAUDE.md`.
- `allowed_tools`: Explicitly defined for most agents.

### 2. Tool Definition
The project extensively uses the `@tool` decorator pattern. Tools are defined with clear names, descriptions, and input schemas (though some use `dict` instead of full JSON schemas, which is acceptable).

### 3. Permission Handling
The main orchestrator (`core/orchestrator.py`) implements a robust `_permission_callback` that:
1. Generates a unique `request_id`.
2. Emits a `TOOL_EXECUTION` event via WebSockets.
3. Waits for a user response via a `Future`.
4. Returns `PermissionResultAllow` or `PermissionResultDeny`.

### 4. Streaming & Response Handling
Streaming is handled using the standard SDK pattern:
```python
async for message in client.receive_response():
    if isinstance(message, AssistantMessage):
        for block in message.content:
            if isinstance(block, TextBlock):
                # Process text
            elif isinstance(block, ThinkingBlock):
                # Handle thinking
```
