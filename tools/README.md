# Hypr-Voice Tools

This directory contains utility scripts and tools organized by functionality.

## 📁 Directory Structure

### Image Generation (`image-generation/`)
External API client scripts for image generation services:

- **[tensorart.py](image-generation/tensorart.py)** - Tensor.Art API client for generating images using specific models
- **[cfs-image-gen.py](image-generation/cfs-image-gen.py)** - Cloudflare Workers AI image generation API client

## 🛠️ Usage

These tools are standalone utilities that complement the main Hypr-Voice functionality but are not part of the core system.
